# Security

## Reporting a vulnerability

Report it privately through [GitHub's vulnerability reporting](https://github.com/felix-bohlin/ui/security/advisories/new), not in a public issue. Include the `opui-css` version, the affected component, element or script, and the steps to reproduce it. You get a reply within a week.

## Supported versions

Security fixes go into the latest release of `opui-css`.
