# Audit: accessibility

Findings on `feat/new-components-and-fixes` at `961b291`. Paths are relative to `packages/opui/` unless they start with `src/` or `tests/`. Severity: **high** = users of assistive tech are blocked or misled, **medium** = degraded, **low** = polish.

| #   | Issue                                                                                                                                                                                                                                                                                                                                                                                                                                       | Severity | Potential fix                                                                                                                                   |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | `error` never sets `aria-invalid` (only `data-invalid` on the wrapper) on TextField, Textarea, Select, ClassicSelect, Checkbox, Radio, Switch, Range.                                                                                                                                                                                                                                                                                       | high     | Set `aria-invalid="true"` on the control and link the error text via `aria-describedby`.                                                        |
| 2   | `FieldDescription` has no id and can't be linked; `FieldGroup`/`ButtonGroup`/`ToggleGroup` have `role="group"` but no way to name them (`role` is set after `rest`, so it can't be overridden either).                                                                                                                                                                                                                                      | medium   | Generate an id and expose it via context; accept `aria-label`/`aria-labelledby`.                                                                |
| 3   | Tabs: `role="tablist"` on a div of radios, `role="tab"` on a non-focusable `<label>`, no `aria-selected`; screen readers hear "radio button". `tests/e2e/a11y-known-violations.json` accepts `aria-allowed-role` and `aria-required-children` on `tabs/Basics` for this. No vertical orientation, no disabled tab.                                                                                                                          | high     | Either honest `radiogroup` semantics, or real tabs (buttons, `aria-selected`, roving tabindex).                                                 |
| 4   | Callout: `role="note"` on the root triggers `aria-allowed-role` on all three callout examples (accepted in the ledger); heading hard-coded to `<h3>`; icon SVGs lack `aria-hidden`; `success`/`neutral` have no default icon.                                                                                                                                                                                                               | medium   | Use an element that allows `note` (or drop the role), add a `headingLevel` prop, hide the SVGs.                                                 |
| 5   | Accordion: `role="region"` on every panel (ARIA APG advises against with many panels), redundant `aria-controls` on `<summary>`, HTML comments emitted into the page (`Accordion.astro:32,49,59`).                                                                                                                                                                                                                                          | low      | Drop the region role and the comments.                                                                                                          |
| 6   | Dialog never sets `aria-labelledby`; `DrawerHeader.astro:16` renders the heading as a `<span>`; the Drawer close button is named only via `title="Close"` (English only, SVG not hidden).                                                                                                                                                                                                                                                   | high     | Generate an id for the heading and set `aria-labelledby`; `headingLevel`/`as` and `closeLabel` props; `aria-hidden` on the SVG.                 |
| 7   | Card and Dialog headers use `<hgroup>`, which only allows one heading plus `<p>`; any other header content is invalid.                                                                                                                                                                                                                                                                                                                      | low      | `<header>` with an inner `<hgroup>` when needed.                                                                                                |
| 8   | Badge `aria-label` sits on a plain `<span>`, where ARIA doesn't allow naming; a bare "3" also means little.                                                                                                                                                                                                                                                                                                                                 | medium   | Visually hidden text (`srLabel` prop: "3 unread").                                                                                              |
| 9   | Avatar: no default `alt`, initials have no `role="img"`/label, groups can't be named.                                                                                                                                                                                                                                                                                                                                                       | medium   | Require `alt` for images, `role="img" aria-label` for initials, `aria-label` on groups.                                                         |
| 10  | Buttons: a disabled `<a>` drops `disabled` instead of rendering `aria-disabled="true"` + `tabindex="-1"` (the CSS supports it; `Menu.astro:55` does it); no `label` → `aria-label` prop for icon-only buttons; no default `type="button"` so buttons inside forms submit; no forced-colors `GrayText` for disabled.                                                                                                                         | medium   | Render `aria-disabled`/`tabindex`; add `label`; default `type="button"`; `@media (forced-colors: active)`.                                      |
| 11  | Carousel: "Previous"/"Next" hard-coded in `carousel.css:106-143`, no `aria-roledescription="carousel"`, no slide labelling, no `:focus-visible` style on `::scroll-button()`/`::scroll-marker`; markers are background-only so they vanish in forced colors.                                                                                                                                                                                | medium   | `--_button-prev-label`/`--_button-next-label`; `aria-roledescription`; `aria-label` per item; focus and forced-colors styles.                   |
| 12  | Divider has no vertical orientation / `aria-orientation`. Table `HeaderCell` never defaults `scope`; no `Caption` component; no `aria-sort` support.                                                                                                                                                                                                                                                                                        | low      | Add `orientation`; default `scope="col"`; add `Caption`.                                                                                        |
| 13  | Menu: no `aria-keyshortcuts` for `shortcut`, no `aria-label`, no `.ui-disabled`. Arrow-key navigation is already in TODO.md.                                                                                                                                                                                                                                                                                                                | medium   | Add the attributes; style `[aria-disabled]`.                                                                                                    |
| 14  | Toast pauses on `:hover` only, not `:focus-within` (WCAG 2.2.1); every toast is `role="alert"`; the focus ring on inverted toast/tooltip surfaces is nearly invisible because the global ring inverts the page background, not the local one.                                                                                                                                                                                               | medium   | Pause on `:focus-within`; `role="status"` for non-critical; set `--focus-ring-color` on inverted surfaces.                                      |
