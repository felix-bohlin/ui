# Audit: missing features and modern CSS opportunities

Findings on `feat/new-components-and-fixes` at `961b291`. Paths are relative to `packages/opui/`. Severity here means how often users of a component library will expect it: **high** = commonly needed, **medium** = nice to have, **low** = exploratory.

## Missing features

| #   | Issue                                                                                                                                                                                                                                                                                                                        | Severity | Potential fix                                                                                           |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------- |
| 1   | Button: no `loading` state (the spinner already keys off `aria-busy`), no start/end icon slots, no full-width option, only two intent colours, no `aria-pressed` style. `.ui-ripple` disables the background hover for every variant and the halo sits behind an opaque `filled` background (`button.css:108-121, 252-284`). | high     | `loading` prop → `aria-busy`; `spread`; keep a hover for filled ripple buttons.                         |
| 2   | TextField: no clearable, character counter, password reveal, `large`/`x-small` (tokens exist), `:placeholder-shown`, search-cancel or number-spinner styling.                                                                                                                                                                | medium   | Add opt-in parts (`clear` slot, `maxlength` counter); use `--field-size-large`.                         |
| 3   | Textarea: no character counter; `field-sizing: content` has no `max-block-size` cap so it grows without limit.                                                                                                                                                                                                               | medium   | Counter from `maxlength`; `max-block-size: 20lh` default.                                               |
| 4   | Select: `items` can't express disabled items, option groups or a selected item; no `option:disabled`/`optgroup` styling; no picker `max-block-size`; no `value` prop in Astro.                                                                                                                                               | high     | Extend `Item` with `disabled`/`group`; add `value`.                                                     |
| 5   | Avatar: no initials fallback, image-error fallback, sizes, status badge, or `AvatarGroup` with max/"+N" (the last avatar also gets the negative margin).                                                                                                                                                                     | medium   | `size`, `fallback`, `AvatarGroup`.                                                                      |
| 6   | Badge: no max count ("99+"), `showZero`, or standalone use without wrapped content.                                                                                                                                                                                                                                          | medium   | `max` prop, `standalone`.                                                                               |
| 7   | Chip: no removable/dismiss button, selectable state, disabled/`aria-disabled`, focus-visible style, colours or large size.                                                                                                                                                                                                   | medium   | `removable`, `selected`, `disabled`, `color`.                                                           |
| 8   | Progress: no circular variant, visible label/value, sizes, intent colours, explicit `indeterminate` flag (only by omitting `value`), `<meter>` styling, or a static fallback under reduced motion.                                                                                                                           | medium   | `circular`, `label`, `indeterminate`; pulse fallback.                                                   |
| 9   | Tooltip can't wire its own trigger: users must pass `id` + `interestfor` + `commandfor` + `command` by hand (see `src/component-examples/tooltip/Basics.astro`); no `delay`; the arrow ignores `flip-block` (`tooltip.css:44`).                                                                                              | high     | Expose the id as a slot prop or require `id`; `interest-delay`; anchored container query for the arrow. |
| 10  | Menu: no `MenuItem` component, checkbox/radio items, separators (only `borderTop`), `overscroll-behavior` on the list, or a fallback without anchor positioning; submenus/groups only in HTML.                                                                                                                               | medium   | `MenuItem`, `MenuSeparator`, `role="menuitemcheckbox"` items.                                           |
| 11  | Tabs: no vertical orientation, `v-model`, `items` prop or disabled tabs.                                                                                                                                                                                                                                                     | medium   | `orientation`, `items`, `disabled`, `v-model`.                                                          |
| 12  | Table: no caption/footer components (`table.css:88,102` already style them), sortable headers, selected/striped rows, `tabular-nums`, scroll wrapper; sticky header is in TODO.md.                                                                                                                                           | medium   | `Table.Caption`, `Table.Foot`, `striped`, `selected` row.                                               |
| 13  | Dialog: no sizes/fullscreen/scroll modes, `DialogHeader`/`DialogFooter` helpers, or backdrop fade (Drawer has one). Drawer: no size prop, no `overscroll-behavior: contain` on content.                                                                                                                                      | medium   | `size`, `fullscreen`, header/footer parts.                                                              |
| 14  | Card: no clickable/link card (`as`/`href`) or media slot; `overflow: hidden` clips focus rings; `[class="ui-button"]` exact matching (`card.css:98,102,110`) is brittle.                                                                                                                                                     | medium   | `as`/`href`, `media` slot; `overflow: clip` with `overflow-clip-margin`.                                |
| 15  | Accordion: no group wrapper or disabled state. Checkbox/Radio/Switch: no `label` prop, no `RadioGroup`, Radio lacks `spread`, no `[data-indeterminate]` no-JS fallback, no check/dot transitions; Switch lacks `:user-invalid`, forced-colors and large.                                                                     | medium   | Fill the gaps per component.                                                                            |
| 16  | Range: no `showValue` (today `valueSuffix=""` is the workaround), two-thumb range, `:focus-visible` thumb style or vertical orientation.                                                                                                                                                                                     | low      | `showValue`; thumb focus style.                                                                         |
| 17  | DescriptionList has no `items` prop (recommended by `components/AGENTS.md` §7); Divider has no vertical or text variant; List has no disabled item and `list.css:18-23` disables text selection on touch.                                                                                                                    | low      | Add `items`; `orientation`; `[aria-disabled]` styling.                                                  |
| 18  | Vue `v-model` missing on ToggleButton, ToggleGroup, Tabs and `v-model:open` on Accordion/Dialog/Drawer.                                                                                                                                                                                                                      | high     | `defineModel` in each.                                                                                  |

Nothing at all: Skeleton, Pagination, Breadcrumb, Stepper, NumberField, Combobox, DatePicker, generic Popover, Rating, Toolbar/AppBar, EmptyState, VisuallyHidden.                                                                       | medium   | Prioritise Link, Spinner, Skeleton, Pagination, Breadcrumb.                                             |

## Modern CSS opportunities

Checked what is already used before listing. Anchor positioning, `@starting-style`, `light-dark()`, `field-sizing`, `::details-content`, `::scroll-button()`, `appearance: base-select`, `if()`, `@scope` and style queries are all in use somewhere.

| #   | Issue                                                                                                                                                                                                                                                                                                                 | Severity | Potential fix                                                                     |
| --- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- | --------------------------------------------------------------------------------- |
| 1   | `@starting-style` is used in dialog, drawer, menu, select, tooltip but not for Toast entry (`toast-enter` keyframes) or the dialog `::backdrop`.                                                                                                                                                                      | low      | Replace the enter keyframes with `@starting-style` + `transition`.                |
| 2   | `@property` is registered for the palette only. `--motion` (in TODO.md), `--_track-fill` (`<percentage>`, animatable) and the `--palette-hue` type are candidates; 34 palette registrations use `initial-value: transparent`, so a broken chain silently makes text invisible.                                        | medium   | Register the three; use a visible initial value.                                  |
| 3   | `if()` is used only in carousel. It fits `scroll-behavior` from `--motion` and card shadow from `--color-scheme`.                                                                                                                                                                                                     | low      | `scroll-behavior: if(style(--motion: 0): auto; else: smooth)`.                    |
| 4   | `@scope` is used only for rich text. It would stop nested components leaking (`.ui-checkbox .ui-label`, `.ui-callout svg`, list-in-list).                                                                                                                                                                             | medium   | `@scope (.ui-callout) to (.ui-button, .ui-list)`.                                 |
| 5   | `anchor.css` has no `position-try-fallbacks`/`position-visibility` (tooltip and menu do). Anchor positioning could also drive a sliding tab indicator and an anchored container query for the tooltip arrow after `flip-block`.                                                                                       | medium   | Copy the fallbacks from tooltip; try anchored queries.                            |
| 6   | `scroll-state()` container queries are unused: sticky table header shadow, dialog/drawer scroll shadows (in TODO.md), carousel `snapped` for the active slide.                                                                                                                                                        | medium   | `container-type: scroll-state` on the scrollers.                                  |
| 7   | Container queries: fix the self-queries (CSS bug #26); make Card an `inline-size` container so its actions can wrap.                                                                                                                                                                                                  | low      | Wrapper containers.                                                               |
| 8   | `corner-shape` is used only in avatar; a theme-wide `--corner-shape` would let squircle apply to buttons, cards, chips.                                                                                                                                                                                               | low      | `corner-shape: var(--corner-shape, round)` in the root rules.                     |
| 9   | `contrast-color()` (in TODO.md) also fits badge and avatar text and the critical button contrast.                                                                                                                                                                                                                     | low      | `color: contrast-color(var(--_bg))` with a `@supports` fallback.                  |
| 10  | `overscroll-behavior: contain` is missing on menu, drawer content, `pre` and the select picker; `.ui-scroll-lock` only matches `[open]`.                                                                                                                                                                              | low      | Add it; match `:is([open], :popover-open, :modal)`.                               |
| 11  | `inert` has no styling (pairs with disabled fieldsets); `content-visibility: auto` + `contain-intrinsic-size` would help long lists and tables.                                                                                                                                                                       | low      | `[inert] { opacity: … }`; opt-in `.ui-lazy`.                                      |
| 12  | `text-wrap: pretty` is used for body text; `balance` fits headings and card/callout/dialog/toast titles.                                                                                                                                                                                                              | low      | `text-wrap: balance` on `.ui-h1…h6` and titles.                                   |
| 13  | `:user-valid` is in TODO.md; Switch and Select still lack `:user-invalid`.                                                                                                                                                                                                                                            | medium   | Add both.                                                                         |
| 14  | View transitions: toast add/remove (`view-transition-class`) and tab panel switching.                                                                                                                                                                                                                                 | low      | `view-transition-name` per toast.                                                 |
| 15  | `::checkmark` for select (replacing `::check`); the `::scroll-marker`/`:target-current` pattern used by carousel could also build Tabs.                                                                                                                                                                               | low      | Prototype Tabs on scroll markers.                                                 |
| 16  | `reading-flow: flex-visual` for `.ui-tabs`, which reorders with `order` (`tabs.css:62,81`).                                                                                                                                                                                                                           | medium   | Add it so focus order follows the visual order.                                   |
| 17  | `sibling-index()`/`sibling-count()`: avatar-group stacking, toast stack depth (replace the commented `nth-last-child` cap at `toast.css:27-29`), staggered menu entry.                                                                                                                                                | low      | `z-index: calc(var(--count) - sibling-index())`.                                  |
| 18  | `margin-trim` for rich text and `.ui-content` (replacing `> :first-child`/`:last-child` margin resets).                                                                                                                                                                                                               | low      | `margin-trim: block`.                                                             |
| 19  | `@media (scripting: none)`: `[data-indeterminate]` fallback for checkboxes, hiding the toast manager.                                                                                                                                                                                                                 | low      | Add the media block.                                                              |
| 20  | `prefers-contrast` / `prefers-reduced-transparency` in the theme (stronger `--border-color`/`--text-muted`, no backdrop blur); scroll-driven animation for a CSS-only range fill; typed `attr()` needs a fallback (CSS bug #24); `interpolate-size` is redeclared in `accordion.css:32` though inherited from `html`. | low      | Add the media blocks; try a view-timeline on the thumb; delete the redeclaration. |
