# Divider

It's just a line.

**Quick start**

### npm

```sh
npm install opui-css open-props
```

```css
@import "opui-css/css/components/divider.css";
```

### CDN

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/opui-css/dist/opui.css" />
```

### Copy the CSS

[Jump to source](#installation)

[Full setup guide](https://open-props-ui.netlify.app/html/guide/getting-started.md)

## Default

```html
This text is placed over
<hr class="ui-divider" />
This text is placed under
```

## Variants

```html
Tonal
<hr class="ui-divider ui-border-tonal" />


Filled
<hr class="ui-divider ui-border-filled" />


Primary
<hr class="ui-divider ui-border-primary" />
```

## API

| Type    | Modifiers                                                     | Default | Description               |
| ------- | ------------------------------------------------------------- | ------- | ------------------------- |
| Variant | `.ui-border-tonal`, `.ui-border-filled`, `.ui-border-primary` | -       | Visual variant modifiers. |
