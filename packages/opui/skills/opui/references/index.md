# References

Guides: `getting-started.md` (setup, with a section per framework), `theming.md` (colors, scopes, density, spacing, corners, fonts, elevation, motion and contrast) and `customizing.md` (the `theme.custom` layer and component properties).

Each component reference covers HTML, Astro, React, Svelte and Vue: the parts, props, classes, slots and notes they share, the component properties and theme tokens, then a section per framework with its import line, slots, hydration and an example.

| Component | File | Description |
| --- | --- | --- |
| Accordion | `accordion.md` | A summary that opens to show more content, on its own or in a group. |
| Anchor | `anchor.md` | Floating content placed next to an element with CSS anchor positioning. |
| Avatar | `avatar.md` | An image, initials or icon that stands for a person or an entity. |

| Callout | `callout.md` | A message in the flow of the page, without interrupting the task. |

| Carousel | `carousel.md` | A scrolling list with snap points, buttons and markers. |
| Checkbox | `checkbox.md` | A box people check for choices submitted with a form, alone or in a group. |
| Chip | `chip.md` | A compact label or control for filters, tags and choices. |

| List | `list.md` | Rows of similar items, like contacts, files or settings, with icons, controls and links. |
| Menu | `menu.md` | A popover list of actions or links. |
| Message | `message.md` | Chat bubbles that group by sender, with attachments, reactions and a typing indicator. |

| One-time code | `one-time-code.md` | A one-time password (OTP) field: one input drawn as a box per character, with paste and SMS autofill. |
| Progress | `progress.md` | A progress bar on the native progress element, for a task that reports how far along it is, or one that doesn't. |
| Radio | `radio.md` | Radio buttons for picking one option from a few, with sizes, cards and an invalid state. |
| Range | `range.md` | A slider for picking a number by moving a thumb along a track. |
| Rating | `rating.md` | A star rating: a meter that shows a score, or radios that collect one. |
| Select | `select.md` | A dropdown for picking one value from a list in a form. |
| Spinner | `spinner.md` | A spinner on any element with aria-busy="true", for content that is loading. |
| Stat | `stat.md` | A number with its label and its change, like revenue on a dashboard. |
| Stepper | `stepper.md` | A list of steps that shows where someone is in a flow, like a checkout. |
| Switch | `switch.md` | An on and off switch for a setting that applies right away. |
| Table | `table.md` | A table for data people scan and compare, with sticky headers, sorting and expandable rows. |
| Tabs | `tabs.md` | Tabs that switch between panels of related content, built on radio inputs. |
| Text field | `text-field.md` | A single-line text input with a label, start and end text, and validation. |
| Textarea | `textarea.md` | A multi-line text input with a label, start and end text, and validation. |
| Timeline | `timeline.md` | A list of dated events with markers and a connecting line. |
| Toast | `toast.md` | Short messages that confirm an action and dismiss themselves. |
| Toggle | `toggle.md` | Buttons that switch options on and off, alone or in a group, like bold in a toolbar. |
| Tooltip | `tooltip.md` | A short label or hint for a control, shown on hover and focus. |
| Typography | `typography.md` | Text styles: classes on single elements, or .ui-rich-text around content. |
