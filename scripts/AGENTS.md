# The example and component generators

`pnpm build-examples` (`scripts/build-examples.mjs`) renders every `.astro` example in `src/component-examples/` and writes its HTML, React, Solid, Svelte and Vue files. It refuses what it can't convert: every unsupported construct throws an error that names the file and the construct, and nothing is guessed. The output is checked against the Astro render, never against the generator itself.

## Modules

Each module owns one invariant, and one test enforces it.

## Workarounds

Every workaround for a bug in `@astrojs/compiler`, Astro, parse5 or oxfmt has a repro in `tests/unit/tooling-bugs.test.ts` that fails when a dependency update fixes the bug; the failure names the workaround to remove. The components stay independent of how oxfmt wraps their source: `tests/unit/component-formatting.test.ts` renders each one from its source formatted at printWidth 40 and 200.

## Adding support for a construct

- Reject first: throw `unsupported(file, what, target, hint)` with the fix, then make it work.
- A new rule comes with a sample it must flag, and with its line in the root `AGENTS.md` Testing section.
- A list that could be derived (React's value-holding components, the input types React fixes, the custom element tags) is derived in a test, not maintained by hand.
- Run `pnpm build-examples` and commit the regenerated files with the change.
