The same accordion three times. The middle one puts back the browser's list-style on the summary, which is what dropping list-style: none does; the display: none on ::marker does nothing in any engine, since display isn't one of the properties that apply to a marker, so it isn't undone here. No disclosure triangle shows, because the summary is display: flex and a marker box only exists on display: list-item. The right one sets display: list-item to show that the triangle is there to hide otherwise. Safari drew the triangle as ::-webkit-details-marker, which display: flex doesn't remove, until WebKit moved summary to display: list-item and ::marker in November 2024 (WebKit commit cd2f382), so only the Safari releases before that change need the vendor rule. Open this page in Safari to confirm the middle column shows no triangle there.
