Current

All but the last control in each row have aria-invalid="true". Invalid only sets --primary to red, so checkboxes and radios turn red when checked, and an unchecked one looks valid. The switch gets a red ring either way. Check the required checkbox and uncheck it: it is now :user-invalid, but nothing on the box changes.

With the fix

An unchecked invalid checkbox or radio gets a red border (--invalid-color, like the text field border and the switch ring), so it reads as invalid in every state. The required checkbox turns red once it is unchecked again.
