The group lines its controls up at the bottom (align-items: end), which is what puts a button level with a field that has a label above it. Help or error text under the field is part of the field's box, so in A the bottom of that box is the bottom of the text, and the input ends up above the button by the height of the text. In B the text comes after the group, linked with aria-describedby, as the Labels section of the docs asks, and the input and the button share one line.

One code per order.

B: help text after the group

One code per order.

The same with an error, where the text is two lines in a narrow group: the gap in A grows with every line, which is why no fixed offset on the button can close it.

This code has expired. Codes are valid for 30 days.
