Each group is 15rem wide, so its last two buttons wrap to a second row. A is a group of buttons only: the lines between the buttons are gap rules (column-rule), which the browser draws between two items of a row and never before the first, so Snooze starts its row clean. B has a field with a visible label. A rule runs the full height of the row and would show beside the label, above the controls, so this group keeps the older way: every button after another control paints its own start border. Copy link is such a button wherever it lands, so it starts the second row with a line. C is the same group with the label hidden, which draws rules again.
