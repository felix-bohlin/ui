For iPhone and iPad. Tap each field and type six digits, one at a time. The first field has the iOS block from css/compat/one-time-code.css, which gives the input a fixed width. The second undoes the block, so the input sizes itself to its text with field-sizing: content, as in other browsers. If every digit, the sixth too, shows in its box while the second field has focus, iOS Safari handles it and the block can go. On a desktop browser both fields work the same, since the block only applies on iOS.
