For iPhone and iPad. Open File, then Export, in both menus. The first menu has the iOS block from css/compat/menu.css, which anchors the submenu to the whole menu, so its top lines up with New. The second undoes the block, so the submenu uses Export as its anchor, as in other browsers. If the second submenu opens level with Export on the device, iOS Safari places submenus right and the block can go. On a desktop browser both open level with Export, since the block only applies on iOS.
