Each row sets a theme's field tokens on a wrapper and puts a text field next to the code for comparison: m3's 4px field radius, brutalist's 5px radius with 2px borders, and a 16px field radius. Today the boxes come from SVG data URIs with rx='8' and a stroke clipped to 1px (2px with focus), so they keep the default look in every row. The right column draws the same boxes from gradient mask layers instead, sized by --ui-field-radius (else --ui-radius, capped half a pixel under a third of the box, past which a corner's ring would reach into the next corner and show as a faint tick there) and --ui-field-border-width: per cell a top, a bottom and the two side edges as linear gradients, and the four corner arcs as radial-gradient rings cut to the corners by two more gradients with mask-composite: intersect, nine layers repeated along the row like the SVG is today. The side edges start 1px inside the corners, since Chromium snaps a mask layer's position to whole pixels and a fractional radius would otherwise leave a notch where a side meets its corner. The slot box behind the next empty cell becomes a real border with that radius. Tab into a code to see the focus state.
