One <input> per code, so typing, paste, undo, SMS autofill and screen readers work like any text field. Monospace ch plus letter-spacing put each character in a box drawn by a repeating mask. Click a box and type: the ring marks the next empty slot, because field-sizing: content makes the input exactly as wide as its value.
