Turn on forced colors: a contrast theme in Windows, or in Chrome DevTools, Rendering, then "Emulate CSS media feature forced-colors: active". The first range is as it ships: forced colors mode drops every background image that isn't a url(), and the fill is a gradient, so the whole track shows in CanvasText. The second adds forced-color-adjust: none to the track, which keeps the gradient, so the filled part shows in SelectedItem. Its colors are system colors already, so the theme's colors still apply. Without forced colors the two look the same.
