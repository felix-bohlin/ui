For VoiceOver in Safari. Both tables hold the same data. The first is as it ships: .ui-rich-text makes a table display: block so it can scroll, which in Safari has a record of turning a table into plain text. The second keeps the table a table and scrolls a wrapping div instead, focusable and named by the caption so keyboard users can scroll it. With VoiceOver on, move to each table (VO+Command+T jumps to the next one) and read the cells: if the first is announced as a table with its column and row headers, the item can go; if only the second is, option A holds.
