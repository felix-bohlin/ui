With dense auto-placement

Same markup, no per-tab rules, works in every browser. The radios get a row of their own above the tabs, and grid-auto-flow: column dense fills each row from the first column, so radio n lands in the same column as tab n. A 1px radio in the middle of the column scrolls its tab into view on focus, like today. Tab 30 works like tab 3.

With sibling-index()

Same markup, one rule instead of 20. Each tab is an input, a label and a panel, so input n is sibling n × 3 − 2 and grid-column: calc((sibling-index() + 2) / 3) puts it in tab n's column. The container can't count its children for repeat(20, max-content), so the columns become implicit (grid-auto-columns: max-content) and the panel spans calc(sibling-count() / 3) of them. Tab 30 works like tab 3.
