The bug only shows in forced colors. Open DevTools, press Ctrl/Cmd + Shift + P, run "Show Rendering", and set "Emulate CSS media feature forced-colors" to active. The first row then shows the live result, and the numbers update. The second row applies the forced colors separators without emulation.

Live (only differs with forced colors on)

Current

Each toggle button gets a top border and a −1px top margin as its separator, but keeps its height, so every group is one border width short of its control size.

With the fix

Toggle buttons are one border width taller, and icon-only ones one wider, so the borders and the negative margins cancel out.

Simulated forced colors (separators applied without emulation)

With the fix
