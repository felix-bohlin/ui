The Typography chip for marker shows Safari as unsupported because the compat data marks Safari's ::marker as partial, with the note "Safari support is limited to color and font-size". The one marker rule in typography.css sets font-variant-numeric: tabular-nums on the markers of a rich text ol, and WebKit's list of properties that apply to ::marker (PropertyAllowlist.cpp) includes every font property, font-variant-numeric among them. The left list is today's rule, the right one turns it off; with digits of different widths (1 and 8 in most UI fonts), the left markers line up and the right ones don't. The readouts give the computed value on the marker, and a third list tests content on ::marker, which the note also leaves out and the library doesn't use.
